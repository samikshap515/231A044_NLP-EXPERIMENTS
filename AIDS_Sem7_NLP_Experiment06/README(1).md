# NLP Experiment No. 6
## Part-of-Speech (POS) Tagging using NLTK

### Aim

To implement and study Part-of-Speech (POS) Tagging using Natural Language Toolkit (NLTK) and compare the performance of different POS tagging approaches, including the built-in POS tagger, Unigram Tagger, and Bigram Tagger.

### Problem Statement

Part-of-Speech tagging is an important Natural Language Processing (NLP) task in which each word in a sentence is assigned a grammatical category such as noun, verb, adjective, pronoun, determiner, or preposition.

The objective of this experiment is to:

- Tokenize a given text into individual words.
- Perform POS tagging using NLTK's built-in tagger.
- Implement a Unigram POS Tagger using the Treebank corpus.
- Implement a Bigram POS Tagger with the Unigram Tagger as a backoff.
- Compare the tagging results.
- Evaluate the accuracy of the Unigram and Bigram taggers.

### Brief Theory

POS Tagging is the process of assigning a grammatical category to each word in a sentence.

Example:

```text
He is reading a book.
```

Possible POS tags:

```text
He       -> PRP
is       -> VBZ
reading  -> VBG
a        -> DT
book     -> NN
```

A **Unigram Tagger** assigns a tag based mainly on the word itself and learns the most frequent tag for each word from the training corpus.

A **Bigram Tagger** uses contextual information by considering the previous POS tag while assigning the tag to the current word. In this experiment, the Unigram Tagger is used as a backoff tagger.

The experiment uses the NLTK Penn Treebank corpus containing tagged sentences for training and evaluation.

### Implementation Explanation

#### 1. Import Libraries

The experiment uses NLTK modules for tokenization, POS tagging, and the Treebank corpus.

```python
import nltk
from nltk.tokenize import word_tokenize
from nltk.tag import UnigramTagger, BigramTagger, pos_tag
from nltk.corpus import treebank
from nltk import pos_tag_sents
```

#### 2. Download Required NLTK Resources

```python
nltk.download('averaged_perceptron_tagger')
nltk.download('punkt')
nltk.download('treebank')
nltk.download('punkt_tab')
nltk.download('averaged_perceptron_tagger_eng')
```

#### 3. Define Sample Text

```python
sample_text = "He is reading a book. Please book a ticket for me."
```

#### 4. Tokenization

The text is converted into individual tokens using `word_tokenize()`.

```python
tokens = word_tokenize(sample_text)
```

#### 5. Built-in POS Tagging

NLTK's `pos_tag()` function is used to assign POS tags.

```python
rule_based_tags = pos_tag(tokens)
```

#### 6. Unigram Tagger

The Treebank corpus is loaded and used to train a Unigram Tagger.

```python
train_sents = treebank.tagged_sents()
unigram_tagger = UnigramTagger(train_sents)
unigram_tags = unigram_tagger.tag(tokens)
```

#### 7. Bigram Tagger

A Bigram Tagger is created with the Unigram Tagger as a backoff.

```python
bigram_tagger = BigramTagger(train_sents, backoff=unigram_tagger)
bigram_tags = bigram_tagger.tag(tokens)
```

#### 8. Accuracy Evaluation

The Treebank data is divided for testing and the accuracy of both taggers is calculated.

```python
test_sents = treebank.tagged_sents()[3000:]

unigram_acc = unigram_tagger.evaluate(test_sents)
bigram_acc = bigram_tagger.evaluate(test_sents)

print(f"Unigram Tagger Accuracy: {unigram_acc * 100:.2f}%")
print(f"Bigram Tagger Accuracy: {bigram_acc * 100:.2f}%")
```

### Results

The experiment produced the following results:

| Tagger | Accuracy |
|---|---:|
| Unigram Tagger | 96.32% |
| Bigram Tagger | 98.63% |

The sample sentence used was:

```text
He is reading a book. Please book a ticket for me.
```

The POS tags generated by the different approaches were displayed and compared.

The Bigram Tagger achieved higher accuracy than the Unigram Tagger.

### Conclusion

The experiment successfully implemented Part-of-Speech tagging using NLTK. The text was tokenized and POS tagged using NLTK's built-in POS tagger, Unigram Tagger, and Bigram Tagger.

The Unigram Tagger achieved an accuracy of **96.32%**, while the Bigram Tagger achieved **98.63%** on the selected Treebank test data.

The Bigram Tagger performed better because it uses contextual information from neighboring POS tags. This experiment demonstrates the importance of context in NLP-based POS tagging.
