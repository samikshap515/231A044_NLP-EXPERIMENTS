# NLP Experiment No. 8 — TF-IDF and Cosine Similarity

## Aim

To implement **TF-IDF (Term Frequency–Inverse Document Frequency)** for converting text documents into numerical vectors and use **Cosine Similarity** to measure the similarity between documents.

## Problem Statement

Text documents contain words rather than numerical values, so they must be represented numerically before many NLP and machine learning operations can be performed. The objective of this experiment is to convert a collection of documents into TF-IDF vectors and calculate their cosine similarity to identify how closely related the documents are.

## Brief Theory

### TF-IDF

TF-IDF is a numerical representation used in Natural Language Processing to measure the importance of a word in a document relative to a collection of documents.

It combines two concepts:

- **Term Frequency (TF):** Measures how frequently a term occurs in a document.
- **Inverse Document Frequency (IDF):** Reduces the importance of terms that occur in many documents and gives more importance to terms that are relatively uncommon.

The TF-IDF value is commonly represented as:

`TF-IDF = TF × IDF`

In this experiment, `TfidfVectorizer` from scikit-learn is used. English stop words are removed using `stop_words='english'`.

### Cosine Similarity

Cosine similarity measures the similarity between two vectors by calculating the cosine of the angle between them.

The value generally ranges from **0 to 1** for the non-negative TF-IDF vectors used here:

- `1` → highly similar vectors
- `0` → no shared vector direction / no similarity

Cosine similarity is useful for comparing documents based on their word representations.

## Implementation Explanation

### 1. Creating the document collection

The notebook creates five sample documents:

- **D1:** Machine learning enables computers to learn from data.
- **D2:** Computers can learn patterns from data using machine learning.
- **D3:** Natural language processing helps computers understand human language.
- **D4:** The football team won the match yesterday.
- **D5:** Deep learning is a branch of machine learning.

These documents contain both related NLP/machine-learning content and an unrelated football document.

### 2. Importing libraries

The implementation uses:

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity
import pandas as pd
```

- `TfidfVectorizer` converts text into TF-IDF vectors.
- `cosine_similarity` calculates similarity between document vectors.
- `pandas` is used to display the TF-IDF and similarity matrices in tabular form.

### 3. Generating TF-IDF vectors

The following approach is used:

```python
vectorizer = TfidfVectorizer(stop_words='english')
tfidf_matrix = vectorizer.fit_transform(documents)
```

The resulting TF-IDF matrix has a shape of:

`(5, 21)`

This means the five documents are represented using 21 unique terms after English stop-word removal.

### 4. Displaying the TF-IDF matrix

The sparse TF-IDF matrix is converted into a Pandas DataFrame using the vocabulary generated by the vectorizer.

The notebook identifies terms such as:

Each numerical value represents the TF-IDF weight of a term in a particular document.

### 5. Calculating cosine similarity

The experiment calculates document similarity using:

```python
similarity_matrix = cosine_similarity(tfidf_matrix)
```

The resulting matrix contains pairwise similarity scores for D1 through D5.

### 6. Finding the most similar documents

The notebook compares every unique pair of documents and stores the pair having the highest similarity.

The recorded result is:

`Most similar documents: D1 and D2`

`Similarity: 0.643`

D1 and D2 are closely related because both discuss computers, learning, data, and machine learning.

### 7. Additional similarity function

The notebook defines a helper function:

```python
def similar(D1, D2):
    vector = vectorizer.fit_transform([D1, D2])
    similarity = cosine_similarity(vector)
    return similarity
```

It is then tested with:

- D7: `"Deep studying is important and very easy to learn"`
- D8: `"Machine learning is a useful branch of computer engineering"`

The recorded output is:

```text
[[1. 0.]
 [0. 1.]]
```

This indicates that, under the exact TF-IDF representation used for these two separately vectorized documents, there was no shared feature contributing to their cross-document similarity.

## Conclusion

The experiment demonstrates how **TF-IDF** can represent textual documents numerically and how **Cosine Similarity** can be used to compare those representations.

The highest similarity in the given document collection was obtained between **D1 and D2**, with a cosine similarity of **0.643**. The result shows that documents containing similar terminology tend to have higher similarity scores.

The experiment also demonstrates that documents from unrelated topics can have very low or zero similarity when their important vocabulary does not overlap. The final two-document test further shows that similarity depends on the features produced by the TF-IDF vectorizer and the exact preprocessing applied.
